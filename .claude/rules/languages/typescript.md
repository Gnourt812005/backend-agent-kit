# TypeScript Rules

- TypeScript 5+ with `strict: true` in `tsconfig.json`.
- Prefer `interface` for contracts/props, `type` for unions/aliases.
- Use ES modules `import/export`.
- Use Symbol constants for Dependency Injection tokens.
